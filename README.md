# 端股｜個人股票管理

在 Windows 安裝 Node.js 18 或更新版本後，在專案資料夾執行一次 `npm install` 安裝辨識元件。雙擊 `run_local.bat` 或執行 `npm start`，再於瀏覽器開啟 `http://127.0.0.1:4174`。

## 專案資料夾

- `frontend/`：網頁介面、樣式、前端程式、PWA manifest、Service Worker 與圖示。
- `backend/`：Node.js API 伺服器。
- `database/`：Supabase 資料表與 RLS SQL。
- `config/`：環境變數範本；實際 API 金鑰仍放在 Windows 的 `%LOCALAPPDATA%\Canggu\config.env`。
- 根目錄：本機啟動腳本、`package.json`、Render 部署設定與本說明。

## 公開部署（GitHub + Render）

此專案含 Node.js API，不能只用 GitHub Pages。先建立 Supabase 專案，於 SQL Editor 執行 `database/schema.sql` 建立雲端資料表與 Row Level Security（RLS）規則，再在 Authentication 啟用 Email/Password 登入，並把 Supabase 的 Site URL／允許導向網址設為 Render 網站網址。將程式推送到 GitHub 後，在 Render 選擇 **New + → Blueprint** 並連接此儲存庫；建立服務時填入 `SUPABASE_URL` 與 `SUPABASE_ANON_KEY`。只使用公開 anon/publishable key；絕不可把 `service_role` 或 secret key 放進程式碼或環境變數供前端讀取。正式環境未設定 Supabase 時，系統會鎖住介面不顯示資料。

每個人用自己的電子郵件與密碼建立帳號。登入後會載入該帳號的雲端紀錄，本機副本也按帳號保留。如果同一帳號在此裝置有待同步編輯、雲端也有更新，登入時會顯示版本選擇。登入前的本機模式及舊版瀏覽器資料保留於原本儲存位置，如需移至帳號，請在本機模式匯出備份再登入匯入。RLS 依登入帳號限制資料列，使用者只能讀寫自己的資料。

公開 GitHub 儲存庫會讓程式碼可見；個人投資資料存於 Supabase，而非 GitHub。Render 免費服務可能在閒置後休眠，首次載入會較慢。Supabase 帳號及資料庫需要由帳戶持有人建立與管理。

### 註冊驗證信與密碼重設

在 Supabase Authentication 啟用 **Confirm email**，並將正式站首頁設為 Site URL 及允許導向網址。本機開發要測信件連結時，另加入實際使用的本機網址。

端股註冊和重設密碼要求至少 12 個字元，包含英文大寫、小寫、數字及特殊符號各一個。在 **Authentication → Sign In / Providers → Email** 將 **Minimum password length** 設為 `12`，並在 **Password requirements** 選擇同時要求上述四類字元，讓 Supabase 也能在伺服器端檢查。既有使用者仍可用原密碼登入。

在 **Email Templates** 的 **Confirm signup** 和 **Reset password** 內加入以下一行。保留原本的確認或重設連結，使用者也可以在端股輸入驗證碼。

```html
<p>端股的電子郵件驗證碼是 <strong>{{ .Token }}</strong>。若這不是你發起的操作，可忽略此信。</p>
```

若使用 Supabase 預設寄信服務，通常只可寄給專案團隊的電子郵件。公開供一般註冊帳號使用前，請設定自訂 SMTP 並用測試帳號確認收得到兩種信件。暱稱由 Supabase Auth 的帳號資料保存，已註冊使用者可從站內「設定」新增或修改。

## 功能

- 新增、編輯、刪除持股，記錄股數、平均成本、備用價格與目標配置比例。
- 從台股庫存截圖批次匯入持股。裝置辨識可讀取有表頭的表格，以及具持有股數等標籤的逐筆明細。預設使用 Tesseract，也可用 PaddleOCR PP‑OCRv6 Small 重新辨識。勾選同意後可選 OpenAI GPT‑6.1 Terra 或 Gemini 3.8 Flash 掃描整張圖片。同代號的既有持股預設略過。
- 自動估算持倉市值、投入成本、未實現損益、已實現損益與累計股利。
- 記錄買進、賣出和股利；買進計入手續費與交易稅後更新平均成本，賣出計算已實現損益。
- 「交易與股利」自動查詢台股與 ETF 的現金配息公告，整理近半年與已公告的未來發放日。能與持股核對的成交紀錄會用來估算除息股數，紀錄不足則標示待確認。發放日後依實際入款金額確認才列入總覽，已登錄的同一除息事件不會再次入帳。
- 區間績效比較可從自選清單加入台股或直接輸入代號，一次比較 2 至 5 檔。用起訖日期內的共同交易日，將 Fugle 還原日收盤價的起點設為 100，呈現區間漲跌、最大回撤與年化波動度。
- 台股持股健檢依市值顯示個股與產業集中度。歷史風險以目前股數固定回放近 90 天，價值、成長、籌碼及技術評分使用可查看的固定規則，資料不足的面向會明確標示。只有查詢的台股代號與日期傳到行情服務；股數、成本與損益保留在瀏覽器。
- 比較目前持倉比例與各檔目標配置比例。
- 在持倉壓力測試選擇市場與幣別，設定整組及個別股票的假設價格變動，按市值影響查看結果並寫入日誌。
- 使用 Ctrl+K 或 Cmd+K 查找功能、持股和自選條目。多功能工作區提供持倉檢查、盤前研究兩組版型，並可在同一瀏覽器儲存自己的面板配置。
- 設定股價高低提醒；網頁開啟並更新官方行情時檢查提醒。
- 記錄法說會、除權息、財報等公司事件與自訂日期；事件日期需自行確認公告。
- 建立投資日誌，記下理由、風險與回顧日期。
- 從證交所與櫃買中心官方開放資料更新最近交易日收盤行情。
- 依股票代號或名稱查詢上市、上櫃股票與 ETF 行情，並建立可分組的自選觀察清單。
- 個股查詢可載入 FinMind 免費台股基本面資料，包括本益比、殖利率、股價淨值比及近 12 個月營收年增率。
- 依持倉比重、最近交易日波動及未實現損益提供研究待辦與風險檢視；門檻為通用提示，不是個人化買賣建議。
- 新聞標題提供原始連結、來源網站入口與 Google News 備用搜尋連結；搜尋後可開啟完整新聞結果。
- 國際事件研究接受海外事件關鍵字，從中英文新聞標題比對台灣上市櫃公司名錄。選用模型並同意後，可補充附有新聞來源的個股與產業傳導推論。模型暫時無法回答時，保留公開資料比對。事件回放按台灣日期比較第 5／20 個交易日收盤價。
- 依 Fugle 日 K 評分排列候選股，完整顯示已完成評分的股票，每頁 10 檔並提供上一頁／下一頁；提供風險試算、相關新聞及公開資訊觀測站公告入口。歷史資料不足或 API 額度受限時，部分股票可能無法完成評分。
- 記錄價格觀察點，依日期比較變化並整理簡單方向摘要。
- 使用密碼加密匯出備份，並支援舊版 JSON 備份匯入。
- 使用個人帳號將持倉、交易、提醒、日誌與自選清單同步至雲端，支援多裝置查看。
- 詢問助理可選擇網站主要頁面作為提問主題，解釋投資概念、財報名詞與系統操作；只在勾選同意後送出主題、問題及最近對話，不會自動傳送持倉資料；每帳號每小時最多 20 次。
- 切換暖色護眼配色；偏好會隨帳號設定同步。
- 支援安裝成手機主畫面上的 PWA，沿用同一個登入帳號跨裝置同步。

## 安裝到手機

先將網站部署到 HTTPS 網址，再用手機瀏覽器開啟。Android 可在 Chrome 選單點「安裝應用程式」或「加到主畫面」；iPhone／iPad 請用 Safari 的「分享」→「加入主畫面」。安裝後以相同電子郵件和密碼登入即可同步資料。行情、新聞與登入需要網路連線；服務工作者只快取程式介面，不快取帳號資料或 API 回應。

## 隱私與資料限制

匯入持股時，裝置辨識會在瀏覽器處理圖片。選擇整圖辨識服務、勾選同意並按下掃描後，端股會將縮放後的圖片傳給所選服務。請先遮蔽券商帳號或姓名。端股只在你確認匯入後儲存持股欄位。整圖辨識每小時最多 20 次。

PaddleOCR 由 `npm install` 準備官方模型與瀏覽器執行元件。首次使用時瀏覽器會從端股下載元件，辨識在裝置上執行，無須設定 API 金鑰。

使用 OpenAI 整圖辨識時，將 `OPENAI_API_KEY` 加到 Render 的 Environment 並重新部署。本機則設定在 `%LOCALAPPDATA%\Canggu\config.env` 並重啟。Gemini 整圖辨識使用既有的 `GEMINI_API_KEY`。

未設定雲端同步時，持倉、交易、提醒、日誌、事件及自選股只存在此瀏覽器的 `localStorage`。設定 Supabase 後，登入帳號會將這些資料及護眼模式設定同步到 Supabase 的 `portfolio_data`，並以 RLS 限制每個帳號只能存取自己的資料；瀏覽器仍保留本機副本。加密備份在瀏覽器內以 PBKDF2 衍生金鑰及 AES-GCM 加密；請另外保存備份密碼，忘記密碼無法還原。雲端同步與加密備份是不同功能。

更新行情時，端股伺服器向證交所與櫃買中心請求公開市場資料。搜尋新聞時，由端股伺服器將股票代號、名稱及查詢關鍵字送至 Google News RSS。點選原文或搜尋連結時，瀏覽器會連到連結所屬的網站。

國際事件研究由端股伺服器向 Google News RSS 查詢輸入的事件與海外公司。選用模型並同意後，事件、補充查詢條件、公開來源摘要與篩出的上市櫃公司名單會傳給所選模型。歷史事件回放使用所選台股和新聞日期查詢 Fugle 日 K。持倉、成本與損益不會自動附到這些查詢。


在個股查詢中按「載入基本面」時，所選股票代號會由伺服器送至 FinMind，讀取估值與月營收資料；不會送出持倉股數、成本或損益。伺服器會快取結果 30 分鐘以減少重複請求。資料可用性及更新時間依 FinMind 來源為準。

使用「詢問助理」時，只有在勾選同意並送出後，所選主題、問題及最近 10 則對話才會傳給已設定的 AI 服務；程式不會讀取該主題頁面或附加持倉、成本、損益、登入資料或帳戶資料，對話也不會保存在本機或雲端。若填入股票代號，伺服器會向 Fugle 查詢日內報價與近 150 天歷史日 K，計算 SMA 20／60、RSI 14、MACD、近 20 個交易日高低與 ATR 參考值，再將摘要送給 AI。只有報價時會標明歷史趨勢資料不足；AI 依條件情境提供一般研究參考，不保證報酬或給個人化下單指令。預設 Gemini 需要在 Google AI Studio 建立 API 金鑰，並把 `GEMINI_API_KEY` 設為 Render 環境變數；本機可放入 `%LOCALAPPDATA%\Canggu\config.env`。若改用 Ollama，將 `AI_PROVIDER=ollama`、`OLLAMA_BASE_URL=http://127.0.0.1:11434`、`OLLAMA_MODEL=你已下載的模型名稱` 放入本機 `config.env`，重新啟動本機網站服務，並在本機安裝與啟動 Ollama、下載相同模型。此設定會讓本機 Node.js 後端呼叫 Ollama；提問內容不會送給 Gemini。Render 上的 Ollama 必須有 Render 後端可連線的 Ollama 服務網址；`127.0.0.1` 只會指向 Render 容器本身，無法連到你自己的電腦。

官方開放行情是最新可得交易日的日收盤資料，並非盤中即時報價；非交易日或官方資料更新前會顯示最近交易日。盤中即時報價需接有授權的行情服務。本機服務不會儲存行情或新聞資料。雲端同步設定完成後，登入同一帳號的裝置會互相同步；未設定同步時，瀏覽器資料清除或切換裝置不會自動轉移，請定期下載加密備份。

## Fugle 技術趨勢整合

技術趨勢頁可查 Fugle 歷史日 K，並在本機計算 SMA 20／60、RSI 14 與 MACD，畫出收盤價與均線。查詢只送股票代號，不送持倉股數、成本或損益。資料查詢依 Fugle 方案、API 使用限制與資料授權規則提供。

啟用方式：到 [Fugle Developer](https://developer.fugle.tw/) 申請 API 金鑰；將 `FUGLE_API_KEY=你的金鑰` 存到 `%LOCALAPPDATA%\Canggu\config.env`（例：`C:\Users\你的帳號\AppData\Local\Canggu\config.env`），然後重新啟動 `run_local.bat`。金鑰只由本機 Node 伺服器讀取，不放進 OneDrive 專案、網頁或 Git。請勿將金鑰貼到聊天或公開網站。沒設定金鑰時，技術趨勢頁會顯示設定說明，其他功能仍可使用。


## 加碼試算與 AI 模型選擇

「加碼試算」輸入股票代號或名稱、目前平均買入成本、持股股數、加碼預算與零股／整張單位後，伺服器查 Fugle 最新可得成交價，依公式估算可買股數、加碼後平均成本與剩餘預算。手續費率及賣出證交稅率可自行調整；淨損益與損益兩平價估算會計入加碼買進手續費，以及以目前市值推算的賣出手續費與證交稅，並提供低／現價／高三個買入價情境比較。另以假設年報酬 3%、6%、10% 顯示損平時間情境；不代表預測，且不計入未來加碼、股利與價格波動。可設定每週、每月或每季的持倉檢視提醒，也能把拉桿選定價格存成到價觀察提醒。提醒只會在網站開啟時顯示，不會背景推播或自動下單。券商最低手續費、折扣與滑價可能不同。持倉欄位會送到端股伺服器計算，但不會傳給 Fugle。選 Ollama 分析並勾選同意後，成本、股數、預算與行情摘要會一併傳給目前設定的 Ollama 服務。

「詢問助理」可在每次送出前選擇 Fugle 固定行情摘要、Ollama 或 Gemini；未設定的服務會停用。Fugle 選項需要股票代號，只依報價與歷史日 K 產生固定技術摘要，不會把問題文字或對話傳給 Fugle，也不是 AI 聊天回答。Ollama 或 Gemini 才會收到問題；勾選同意後，若有填股票代號，行情摘要也會一併傳給所選 AI。雲端頁面上的 Ollama 連線位置由管理者設定，若透過 Cloudflare Tunnel 連到本機 Ollama，該電腦、Ollama、轉接程式與 Tunnel 必須維持運作。
